PUBLIKACJA NA GITHUB PAGES
--------------------------
1. Wgraj wszystkie pliki do głównego katalogu repozytorium.
2. Wejdź w Settings > Pages.
3. W polu Source wybierz "Deploy from a branch".
4. Wybierz gałąź "main" i folder "/ (root)", a potem kliknij Save.
5. Po kilku minutach strona będzie pod adresem:
   https://<twoj-login>.github.io/<nazwa-repozytorium>/


DODANIE NOWEJ KARTY
-------------------
1. Wgraj plik architekt_iarp_<nazwa>.html obok index.html.
2. W index.html skopiuj dowolny element <li> z listy ścieżek
   we właściwym obszarze i zmień w nim link, tytuł oraz opis.
